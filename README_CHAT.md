# Simple Chat Application

This is a minimal two-person chat app inspired by WhatsApp. It is built with plain HTML, CSS and JavaScript and works entirely in the browser.

## Features
- Login screen with username input
- Chat bubbles for sent and received messages
- Timestamps, typing indicator and emoji picker
- Messages stored in `localStorage`
- Works in multiple tabs/windows for demo real-time chat
- Dark mode toggle

## Running
Open `src/index.html` in your browser. For a quick demo, open the file in two different windows and enter different usernames. Messages will sync between the windows using `localStorage` events.

No server or build step is required.
